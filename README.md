# GK Snippets Hindi (100 दिन 100 GK सवाल) 🚀

Autonomous automated publishing engine producing and distributing viral 18-second Hindi General Knowledge Shorts/Reels daily.

## 🎯 Architecture
- **Voiceover**: Microsoft Edge TTS (`hi-IN-MadhurNeural`)
- **Typography**: Google Fonts `Noto Sans Devanagari` & `Plus Jakarta Sans`
- **Output Resolution**: 1080x1920 (9:16 Vertical Video)
- **Duration**: Exact 18 seconds (question + 10s countdown + celebration pop answer reveal + CTA outro)
- **Schedule**: 2 videos/day at 8:00 AM & 6:00 PM IST (02:30 & 12:30 UTC)

## 📡 Platforms Synchronized
1. **YouTube Shorts** (`#Shorts`)
2. **Instagram Reels** (`publish_reel`)
3. **Facebook Page Videos** (`publish_facebook_video`)
4. **Telegram Channel** (Instant quiz notification & direct video links)
